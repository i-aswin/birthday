HAPPY BIRTHDAY TO YOU! — SOFT BOTANICAL EDITION

A romantic interactive birthday experience with a minimal welcome screen, soothing eucalyptus / ivory / muted-rose colour grade, interactive games, a single keepsake memory notebook, heartfelt letter, first-gift moment, and the supplied BookMyShow ticket.

The supplied Chellame Magale hook edit is used as looping background music. The site attempts to play it on entry. Browsers may block sound autoplay until the visitor taps or interacts once; the persistent music control can also start or pause it.

Keep index.html and all asset folders together. Open index.html in a browser. If local assets are restricted, run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.
